SHA-256 checksums for the shipped Android build
================================================

Verify a download before installing:

  Linux/macOS :  sha256sum LiquidWeather.apk        (or: shasum -a 256)
  Windows     :  certutil -hashfile LiquidWeather.apk SHA256

Compare the output with the line below. The same digest is shown on the
release page and by the GitHub API for the release asset.
